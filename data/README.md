# Sample data

Every file a lecture reads. The notebooks reference these as `../data/<name>`.

| File | Used by | Notes |
|------|---------|-------|
| `mobydick.txt` | Lectures 14, 18 | Herman Melville, *Moby-Dick*. Public domain. Sourced from Project Gutenberg eBook #2701 with the Project Gutenberg header and license boilerplate removed. |
| `gettysburg_address.txt` | Lecture 23 | Lincoln's Gettysburg Address. Public domain. |
| `people.csv` | Lecture 16 | Three-row example written for the lecture. |
| `students.csv` | Lecture 24 | Four fictional rows; the same data the last cell of Lecture 23 writes. |
| `function_names.txt` | Lecture 19 | List of Python function and method names used in a string-search exercise. |
| `stress.csv` | Lecture 15 | Synthetic wearable-sensor readings (humidity, temperature, step count, stress level), 2,001 rows. Generated by `make_synthetic.py`; no real people. |
| `car_price.csv` | Lecture 9 | Synthetic used-car listings, 2,500 rows. Generated by `make_synthetic.py`; no real vehicles. |
| `movies.txt` | Lectures 14, 15 | Starter list for the Movie List program (three titles). The program reads it on startup and writes back to it when you add or delete a movie, so the file changes as you use the notebook. |
| `scores.txt`, `shelter.pkl` | Final review | Written by the review notebook itself; included so the read-back cells work on their own. |

`make_synthetic.py` regenerates the two synthetic CSVs with a fixed random seed, so they can be rebuilt byte-for-byte at any time: `python data/make_synthetic.py`.
